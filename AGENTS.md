# Project guidance

Personal website built with Docusaurus, React, and TypeScript.

- Follow existing code and content conventions.

## Blog writing

- Write for hiring managers, engineering managers, tech leads, and
  software engineers who read the posts before interviewing me.
- Help readers understand how I approach problems, make technical
  decisions, and learn from experience.
- Explain the problem, relevant constraints, chosen approach, and
  tradeoffs. Include outcomes or lessons where available.
- Make posts easy to scan, with clear headings and concrete examples.
- Give enough context for readers unfamiliar with the project.
- Use a natural, professional voice. Avoid promotional language and
  unsupported claims.
- Distinguish my contributions from the team's work. Do not invent
  experience, results, or metrics.
- Preserve existing post metadata and formatting conventions.
