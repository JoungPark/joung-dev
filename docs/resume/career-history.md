## Second Memory

**2026 – Present**

### AI-Powered Personal Memory Assistant

**Technologies:** TypeScript, Python, Next.js, React, React Native, Expo, NestJS, PostgreSQL, pgvector, Prisma, Redis, Firebase Authentication, RAG, Vector Embeddings, Docker, TurboRepo, pnpm, Render, Vercel, EAS

**Purpose:**

* Building a personal AI assistant designed to capture information such as notes, events and ideas and recall relevant information when needed.
* Exploring how an AI assistant can supplement explicitly recorded memories with personal information from external services such as email, calendars and Notion.
* Designing the system around retrieval-augmented generation (RAG), allowing responses to be grounded in stored personal memories rather than fabricated information.

**Architecture & Development:**

* Designed a full-stack monorepo architecture using TurboRepo and pnpm.
* Developed a Next.js web application and React Native / Expo mobile application.
* Developed backend services using NestJS and TypeScript.
* Developed Python-based embedding functionality.
* Designed PostgreSQL storage with pgvector for vector similarity search.
* Implemented vector embeddings and semantic retrieval for finding memories relevant to a user's question.
* Designed conversation-history and memory retrieval using PostgreSQL and vector similarity.
* Used Redis for supporting application and service workloads.
* Implemented Firebase Authentication, including Google Sign-In for web and mobile applications.
* Designed the application with per-user data isolation in mind.
* Containerised application components using Docker.
* Deployed and experimented with services using Render and Vercel.
* Built Android and iOS applications using Expo Application Services (EAS).
* Worked through mobile authentication, environment configuration and native-build differences between development, preview and production builds.
* Investigated deployment issues involving memory limits, environment variables, CORS, Prisma migrations and service health checks.
* Investigated PostgreSQL / pgvector indexing constraints for high-dimensional embeddings.
* Experimented with local embedding models including `all-MiniLM-L6-v2`.
* Designed prompts that require the assistant to answer from retrieved memories and explicitly acknowledge insufficient evidence rather than fabricate dates or events.
* Explored integration architecture for accessing personal data from Gmail, calendars and Notion, including REST API, OAuth and MCP-based approaches.
* Explored approaches for combining personal RAG data with external web information when answering questions.
